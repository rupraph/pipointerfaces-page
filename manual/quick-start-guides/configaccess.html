WiFi & Page access

Use Pipo over Wifi

To configure your Pipo, you have to access its configuration page using a web browser through Wifi. You can do so from any mobile or computer.

Connection

Your Pipo module configuration page can be accessed either by connecting directly to it, or through your local wifi network. When accessing it for the first time, follow first "Direct connection" steps below.

  • Direct wifi connection to Pipo (AP mode)

    • When Pipo boots, it will automatically create a wifi network that you can connect to
    • By default, it will be named Pipo-Motion, Pipo-Analog, etc... (The name can be changed when using multiple Pipos)
    • Connect to it, the default password is pipo1234
    • You can then access the page, see the section below "Access the page"

  • Connecting Pipo to your network (STA mode)

    • If you never connected to a network, one should first access the config page following the steps above
    • Once in the config page, click on the wifi bars button on the top right corner of the page to open the wifi manager.
    • You can select a network to connect to, enter the password
    • click connect.
    • wait a few seconds
    • the wifi led should start pulsing slowly
    • You can now access the config page from either the direct connection or through your network

      Warning

      Prefer a dedicated or home network to do so. Public or Corporate WiFi will likely be incompatible due to their own security setup

      Tips

      Once Pipo knows a network, it will also try to connect to it at boot

      Tips

      A networks gets unlocked when you have successfully connected once (credentials are remembered).

Access the page

  • Once you are connected, you can access the config page by entering the following adequate URL in your web browser pipo-motion.local,pipo-analog.local or pipo-range.local

    Tips

    When you change the Pipo name in the settings, its URL name will also change
