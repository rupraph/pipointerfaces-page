Wifi & Config page

Prototype

The modules are still under development. Hence these directions are only valid for protytpe testing. Note: some features are not yet implemented, and some are not mature yet.

Any feedback is welcome !

Use Pipo over Wifi

To configure your Pipo, you will need to access its configuration page using a web browser through Wifi. You can do so from any mobile or computer.

Note: if you are willing to use OSC, it is strongly recommended to use a dedicated wifi router.

For Firmware >= v0.0.4

Your Pipo module config page can be accessed either by connecting directly to it, or through a local wifi network.

  • Direct connection to Pipo (AP mode)

    • When Pipo boots, it will automatically create a wifi network that you can connect to
    • By default, you it will be named Pipo-Motion, Pipo-Analog, etc... (The name can be cahnged when using multiple Pipos)
    • The default password is pipo1234
    • Once connected, you can access the config page by entering "pipo-motion.local" in your web browser (or pipo-analog.local, etc...)
    • The Pipo IP in this mode is dipslayed on the top bar as "APIP".

  • Connecting to a network (STA mode)

    • To request pipo to connect to a network, one should first access the config page following the steps above
    • Once on the config page, click on the wifi bars on the top right corner of the page to open the wifi manager
    • You can select a network to connect to, enter the password
    • click connect.
    • refresh the page, you should see the connected network on the top right corner
    • You can now connect your pc or phone on the same network and access the config page from the local wifi as usual at "pipo-motion.local" ( or "pipo-analog.local", etc...)
    • Note: the current IP of the Pipo is displayed in the top Bar as "STAIP"

For Fimware < v0.0.4

  • When you switch on a Pipo, it will always try to connect to its last known Wifi if available.

    • If it cannot connect, Pipo will start a WiFi Access Point called "Pipo" for you to connect to it.
      • In this case, use your phone or computer to conect on this Wifi
      • when you are connected to Pipo, your phone or pc should directly open your browser and bring you to the Pipo wifi manager page (if the window does not open, just open your webbrowser and go to 192.168.4.1)
      • You should now see the Wifi Manager page.
      • click configure wifi
      • select the wifi you want pipo to connect to
      • enter your credentials
      • click save
      • if succesfull, Pipo will restart, and after a few seconds, the Wifi Led on the pipo should start slowly pulsing. This means pipo is connected and running
    • If pipo can connect to previous wifi, it will do automatically

  • Now that Pipo is connected to your wifi, you can access the config page. Depending on your pipo, you can access it at: - pipo-motion.local - pipo-analog.local - pipo-range.local

  • From there you can configure your Pipo Freely:

    • The sensor section allow you to choose the measuring range, in the sensor unit.
    • The output section allow you to customize how your translate and scale the selected range to the verious possible outputs.
