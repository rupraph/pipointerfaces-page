MIDI USB

When connected through USB, Pipo is using generic drivers and should be detected right away by any computer/OS as a Midi Peripheral.

MIDI output style can be chosen independently for each sensor axis present on a pipo: for eg one axis can be used for Midi sending notes, while the other can send continuous controls (CC) When notes are chosen, the user can choose which scale or arpegio will be used, as well as the base note and the number of notes spread along the sensing range.

Note: when connected to a compatible receiving software, HiResolution midi CC can be enabled.
