Pipo Wi-Fi Manager

You can access the wifi manager by clicking on the top right corner of the config page on the icon

Pipo will initially scan the available networks around you.

Symbols:
means you never connected this network, and Pipo does not know the password
: means you already connected in the past to this network, and the password is already available

When Pipo successfully connects to a network, it will remember the credentials, allowing to quickly connect in the future.

When Pipo starts, it will try to reconnect to the last connected network. If it fails, it will try the previous network with known credentials.

If you want to prevent Pipo to connect to a certain network, you can use the button forget so that the credentials of the networks get removed, and will prevent Pipo to connect to it.

Disconnect will only disconnect from the current connected network. To switch network, you should always disconnect first.
