Use Multiple Pipos & Rename a Module

Once configured properly, a lot of Pipos can be used simultaneously. But if you want to access the configuration page of many Pipos from the same type simultaneously, you should first give them a unique name, or configure them one by one (and turning off the others).

Changing Pipo name

When you have 2 Pipos of the same type, it is strongly advised to rename one of them, making them easier to distinguish. For eg, you can have a pipo name "motion" and the other one names "motion1"

Tips

Changing the Pipo name is propagated to the following elements:

  • Wifi name
  • config page URL
  • OSC address prefix
  1. Access the config page
  2. Open the settings panel ()
  3. Change the Pipo name in the dedicated field
  4. Save and reboot
  5. Pipo now has a new wifi name "Pipo-xxxx" and a new access URL: pipo-xxxx.local

Warning

Pipo now has new connection names, so you if you were using a direct wifi connection, you have to reconnect to it like on a new Pipo. As well, your computer might have cached the previous Wifi name (SSID) and might keep displaying the old wifi name. It is advised to forget this old wifi network (SSID) and then the new one should show up.

  • Pipo now has a new Wifi name. Depending on your OS, your mobile or computer might take a while to show the new wifi name.
  • Pipo has now a new access URL. So refreshing the old page won't work. One has to enter the new connection URL in the browser (if xxxx is the new name, hte new URL is pipo-xxxx.local)
