Pipo Beta Firmware (Testers Only)

How to update Pipo ?

Warning

This page hosts a beta version of the firmware. This is intended for beta testers only ! Note that beta version might not be stable.

Warning

Please be aware that performing an update erases any configuration that you migh have set or saved in the Pipo. It will be reset to factory settings. In case you need to revert to the previous software version, it is always possible to flash the previous one, but you won't retrieve your settings.

Tips

Note that for now, this update method is only supported by a few browsers like Chrome, Edge and Opera.
